# House-Price-Prediction
A machine learning project to predict house prices based on features like location, square footage, and number of bedrooms. Built with Python, Scikit-Learn, and pandas.


# What each folder is for
1. data/
stores dataset
2. notebooks/
where we'll write Jupyter notebook
3. models/
store trained models
4. images/
graphs and visualisation
5. src/
resuable python code
